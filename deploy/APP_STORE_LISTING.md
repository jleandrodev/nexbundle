# Listagem na Shopify App Store — NexBundle

Texto pronto para colar no **Partner Dashboard → seu app → App listing**, na **ordem das seções
do formulário**. Cada campo traz o limite de caracteres da Shopify entre parênteses (confira o
contador do próprio campo — os limites mudam de tempos em tempos) e as três versões:
**EN (obrigatório) · PT-BR · ES**.

> ⚠️ **Antes de submeter:** faça o `npm run deploy` com o scope `write_discounts` já ativo e a

> também os preços dos planos, o e-mail de suporte e os dados da empresa nas páginas legais.

## 8. App testing information

**Login required?** Não existe conta separada: o acesso é pelo admin da Shopify (OAuth).
Se a loja de demonstração tiver senha de vitrine, informe abaixo.

🔵 **Screencast URL:** grave 2–3 min (Loom/YouTube não listado) mostrando: instalar → criar
componente com desconto → ativar o bloco no editor de tema → página de produto com o bloco →
adicionar ao carrinho → **checkout com o desconto aplicado** → analytics.

**Testing instructions** (cole este texto):

```
No separate login is required — the app is accessed from the Shopify admin after install.
Demo store: [URL] (storefront password: [SENHA], if any)

1. Install on a development store. OAuth scopes: read_products, write_discounts.
   write_discounts is used only to create the app's own automatic discount (Shopify Function).

2. In the app, open "Components" → "Create component". Pick a main product and one or more
   companion products, choose a layout (side by side / list / compact), set a bundle discount
   (e.g. 10%) under Settings, and Save.

3. Shopify admin → Online Store → Themes → Customize → a product template → add the app block
   "NexBundle" to the page → Save.

4. Open that product on the storefront. The block shows every product with a checkbox, variant
   picker and quantity, plus the bundle total, the discount badge and the savings line.
   Unchecking items down to a single product removes the bundle discount (by design).

5. Click "Add to cart" (or "Buy it now"). The items are added to the native cart with a hidden
   line property (_bt_bundle). At checkout the discount created by the app is applied
   automatically — no discount code needed. The discount is visible in Shopify admin →
   Discounts as "Buy Together — bundle discount".

6. In the app, open "Analytics" for impressions, clicks and CTR.

7. Billing: "Plans" → subscribe (test charge). Every plan has a 7-day free trial. Plans are
   Essential $6.99/mo (50 products), Pro $19.99/mo (200), Enterprise $39.99/mo (unlimited).

8. Languages: admin and storefront follow the Shopify locale (EN / PT-BR / ES); the dashboard
   also has a manual language selector.

9. Privacy: uninstalling triggers app/uninstalled; the compliance webhooks
   (customers/data_request, customers/redact, shop/redact) are HMAC-verified and shop/redact
   deletes all data for the shop. The app stores no customer personal data.

Support: suporte@nexbundle.sprezzia.live · Privacy: /legal/privacy · Terms: /legal/terms
```
